Joint 2.5D geometry and texture flow matching in a single forward pass, producing watertight, full-surface 3D textured meshes without multi-view test-time optimization.

Abstract

Existing text-to-3D methods predominantly rely on expensive per-prompt multi-view score distillation or feed-forward triplane transformers. InversEdit represents 3D shapes as 2.5D Intrinsic Panoramic Networks (IPNs), unrolling both surface texture and radial depth around a central cylinder. By fine-tuning FLUX.1-dev with balanced loss weighting (w=1.0), the model directly generates seamless, high-resolution geometry and texture in a single diffusion process, reconstructible into watertight 3D meshes in milliseconds.

Hole Completion

An IPN only sees the object along horizontal rays, so tops, bottoms and cavities are never observed. We render the generated mesh from views close to the IPN's own (±25°, then ±50°, then ±75°; 4 views per step), mask the pixels whose ray crosses space the IPN never saw, and fill them: a rough guess (a smooth surface spanning the hole) is refined by the base Modality Forcing model with partial noise, so it keeps the shape and viewing angle. Each fill becomes new surface for the next, steeper step. The generated mesh itself is not changed.
